# Unclaimed

Finds transit agencies with free public GTFS feeds that aren't yet covered by the Transit app, ranked by opportunity (population × feed quality).

## Run locally

```
cp .env.example .env
docker-compose up --build
```

- API: http://localhost:8000
- Postgres: localhost:5432
